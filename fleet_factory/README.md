# Passport fleet factory

This factory creates 35 separate, domain-specific OpenGAP agent repositories. Each generated agent has its own manifest, identity, rules, skill, MCP-compatible tool schema, deterministic domain checks, fixtures, tests, README, and four adapter-shaped modules.

The generated repositories are preparation material, not automatic contest submissions. Each one must be reviewed for originality and submitted through the HiDevs platform separately. Do not claim a passport until HiDevs issues it.

```bash
python3 fleet_factory/generate.py
```
